# Assets

Drop your images and files here, then reference them from the HTML pages.

Expected filenames (used by the placeholder pages — rename or update the HTML as you like):

| File | Used on | Notes |
|------|---------|-------|
| `headshot.jpg` | Home | Your portrait, roughly 4:5 (portrait) orientation |
| `resume.pdf` | Resume | A downloadable copy of your resume |
| `writing-1.jpg` … `writing-4.jpg` | Writing | Article thumbnails, ~3:2 |
| `multimedia-1.jpg` … `multimedia-3.jpg` | Multimedia | Project thumbnails, ~3:2 |
| `photo-1.jpg`, `photo-2.jpg`, … | Photography | Gallery images, any orientation |

Images referenced but not present simply hide themselves (the pages won't break),
so you can add them one at a time.
